# Bootcamp Confluent Cloud 2026 — DIO

Material completo do bootcamp de **Data Streaming com Apache Kafka e Confluent
Cloud**: 7 cursos no domínio payments/fraude, do primeiro evento em JSON até um
pipeline fim a fim com CDC, contrato de dados, Flink SQL e operação profissional.

## Comece aqui

| Você quer | Vá para |
|---|---|
| 🏆 **Fazer o Desafio Final** — o pipeline fim a fim | [`repo/desafio-final/`](repo/desafio-final/README.md) |
| 🧩 Código, datasets e schemas usados nas aulas | [`repo/`](repo/README.md) |

## O que tem em cada curso

| Curso | Tema | Hands-on |
|---|---|---|
| 1 | Fundamentos de EDA e Kafka | Sandbox local (Docker) |
| 2 | Confluent Cloud, Schema Registry e Data Contracts | ☁️ Cloud |
| 3 | Kafka Connect e CDC (Debezium + Neon) | ☁️ Cloud |
| 4 | Apache Flink — processamento de streams | ☁️ Cloud |
| 5 | Lakehouse com Tableflow e Iceberg | Conceitual |
| 6 | Real-Time AI | Conceitual |
| 7 | Operação profissional (observabilidade, segurança, custos, DR) | ☁️ Cloud |

> 💰 **Regra de ouro dos créditos**: conector e statement Flink cobram **por
> existir**. Todo guia termina com teardown — siga-o sempre.

Todos os dados são **100% sintéticos e determinísticos** (`seed=42`) — os outputs
dos guias batem exatamente com o que você verá no seu terminal.
